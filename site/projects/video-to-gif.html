Video to GIF Converter

Project Category: Individual Project (Helper Tools Collection)

Python MoviePy Pillow CLI Tooling Batch Automation

This is one of those deceptively simple tools that becomes very useful once you actually need it. Converting a clip to GIF is easy in theory, but meeting exact size limits while preserving useful motion is where the real work begins. I built this to generate web-friendly GIFs with predictable output size and speed control instead of trial-and-error exporting.

Core value: the tool optimizes for constraints that matter in the real world, like a GIF needing to stay below a file-size ceiling for slides, web uploads, or messaging platforms.

Key Features

Exact Size Targets

Supports size limits from 1MB to 50MB, which makes the output usable for web, messaging, and presentation workflows.

Playback Control

Adjust playback speed from 0.1x to 2.0x so the same clip can become a slow walkthrough or a compact highlight.

Automatic Scaling

Reduces resolution and frame rate as needed to meet output limits instead of requiring manual tweaking.

Interactive Or CLI

Can be used quickly through a batch launcher or called directly from the command line for repeat work.

How It Works

  1. Analyze the input video duration, resolution, frame rate, and overall size.
  2. Estimate what resolution and frame-rate adjustments are needed to satisfy the requested size constraint.
  3. Apply playback speed changes without turning the workflow into manual editing.
  4. Generate the final GIF and validate it against the requested target.

Parameters

ParameterMeaningRangeExample

-p / --speedPlayback speed ratio0.1-2.0-p 0.5

Example Usage

advanced_converter.bat
python converter.py "demo.mp4" -s 8 -p 1.0
python converter.py "demo.mp4" -s 5 -p 0.5 -o "slow_demo.gif"
python converter.py "demo.mp4" -s 3 -p 2.0 -o "fast_demo.gif"

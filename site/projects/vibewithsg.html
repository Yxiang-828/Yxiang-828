The Challenge

The distribution shift.

The dataset is constructed for adversarial generalisation. Train and val are lush — green, balanced, forgiving. Test is a desert — four classes are absent, the rocks class is now dominant, and the Bushes / Trees / Grass triplet that the model leans on for context is gone. Anything that overfits the train biome dies on the cliff.

Balanced 11-class split. Trees, bushes, grass, and flowers form a dense vegetation context that supports ground-class disambiguation. Sky is cloudy; rocks are minor (~3.4 % of pixels).

Architecture

DINOv2-L. DPT decoder. Four feature stages.

A DINOv2-L ViT backbone (304 M parameters, self-supervised pretraining on ~142 M images) feeds a DPT decoder that re-assembles four hierarchical feature stages into a dense per-pixel prediction. The backbone is frozen for two phases, then unfrozen with layer-wise learning-rate decay (LLRD 0.75) for the last 8 transformer blocks only.

Stage A · Input

Image stream

Variable-resolution training schedule, normalised with ImageNet statistics, square-padded for ViT.

  • Phase 1: 420 px (½ res warmup)
  • Phase 2 — 4: 644 px (full)
  • Photometric jitter + HFlip aug
Stage B · Backbone

DINOv2-Large ViT

Patch size 14, 24 transformer blocks, 1024-dim hidden states. Four hook stages (6, 12, 18, 24) feed DPT.

  • 304 M parameters
  • Frozen → fine-tuned (last 8 blocks)
  • LLRD 0.75 across unfrozen blocks
Stage C · Decoder

DPT re-assembly

Hierarchical fusion of the 4 ViT feature stages into progressively up-sampled prediction maps.

  • 11-class softmax head
  • Per-class + mIoU losses
  • Multi-scale + HFlip TTA at inference
Training Recipe

Four phases. One H100.

The recipe is engineered to be cheap, reproducible, and to back out cleanly if any phase regresses. Each phase owns one variable: resolution, decoder weights, backbone unfreezing, and inference-time augmentation.

Data Hygiene

Two silent dataset bugs.

Before any training run, I ran a class-distribution audit and a mask-integrity scan. Two silent bugs surfaced — either alone would have collapsed the model's understanding of half the class space without raising any loss-curve signal.

BUG · 01

Missing Flowers = 600 class

The provided class palette legend listed Flowers = 600, but the corresponding RGB triplet was absent from every training mask. Models trained against this palette would silently never learn the class — and would not be penalised by the val loss because the val masks shared the same gap.

Fix: Re-derived the palette from the actual mask RGB histogram, dropped the orphan class, and verified 11 active classes across train / val / test before any forward pass.
BUG · 02

I;16 mask saturation in PIL

Some masks were stored as 16-bit single-channel TIFF (I;16 mode). PIL's default conversion path clamped values > 255 silently, fusing higher class indices into a single saturated label. A naïve .convert('L') would have lost ~30 % of the high-index pixel-vote.

Fix: Bypassed PIL's mode coercion. Read the raw 16-bit array via numpy.frombuffer, mapped known class IDs explicitly, asserted no truncation pre-train. Verified bit-exact round-trips on a 50-mask held-out probe set.
The Honest Read

Val 0.6361 → Test 0.4214.

The val/test gap is real. The honest read is that this is not overfitting in the classical sense — it is pure distribution shift. The classes that survive the biome change (Sky, Landscape, Path) keep their IoUs almost intact. The classes that vanish or rebalance dominate the drop.

Why the gap is structural, not overfitting

If the model were overfitting the train biome, every class — including the ones it knew well on val — would regress on test. Instead, the IoU drop is concentrated in (a) classes that do not appear on test at all (their IoU collapses to 0 by definition, dragging the mean), and (b) Rocks, where the test class is now 7× more frequent than what the model was trained on.

Video Upscaler

Project Category: Individual Project (Helper Tools Collection)

Python FFmpeg Real-ESRGAN Vulkan AMD AMF Windows CLI

This tool exists because image upscaling is easy to demo, but video upscaling is where the workflow becomes real. Videos are larger, slower, and much more sensitive to bad tradeoffs. I built this to support both high-quality AI upscaling and faster classical scaling while staying practical on my own Windows + AMD GPU setup.

What makes it useful: the project does not just call an AI model and hope for the best. It switches between quality-first and speed-first modes, preserves audio, supports MP4 or GIF output, and falls back to CPU encoding when hardware encoding becomes unreliable at high resolutions.

Why It Matters

Dual Pipeline

Choose between Real-ESRGAN frame-by-frame AI processing for best quality, or classical FFmpeg scaling for faster turnaround.

GPU-Aware

Designed around AMD hardware, using AMF for encoding and Vulkan for AI acceleration where it helps.

Resilient Workflow

High-resolution jobs can automatically fall back to CPU encoding so the tool finishes instead of failing halfway through.

Practical Outputs

Supports MP4 output with audio preservation, plus GIF generation when the goal is sharing a clip instead of storing a full video.

Processing Pipeline

  1. Read the input video and choose the requested upscaling mode.
  2. For AI mode, extract frames to disk and process them sequentially through Real-ESRGAN.
  3. Validate processed frames and reassemble the video with the original audio track.
  4. Use AMD hardware encoding where possible, with CPU fallback for oversized outputs or hardware failures.

Mode Comparison

ModeBest WhenStrengthTradeoff
Real-ESRGANQuality matters more than speedSharper details and stronger restorationMuch slower due to frame-by-frame processing
FFmpeg / ClassicalYou need a faster resultGood throughput with simpler scalingLess detail recovery than AI mode
Extract / Process ExistingYou want control over the pipelineLets you inspect or resume frame workMore manual workflow management

Example Usage

py video_upscaler.py input.mp4 --method realesrgan --scale 4
py video_upscaler.py input.mp4 --method ffmpeg --scale 2
py video_upscaler.py input.mp4 --method process_existing --format gif
video_upscaler.bat

Implementation Notes

  • Supports 2x, 3x, and 4x scaling factors.
  • Uses frame-by-frame processing to avoid loading an entire video into memory at once.
  • Preserves audio during reassembly so the result is useful as a real video output.
  • Can produce GIFs when the goal is communication or quick sharing rather than archival quality.

Requirements

  • Python 3.13
  • FFmpeg available in PATH or bundled locally
  • Real-ESRGAN Vulkan executable for AI mode
  • AMD GPU recommended for the intended workflow

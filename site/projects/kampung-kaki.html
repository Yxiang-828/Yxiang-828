One state, three views

Citizens, responders and ops teams read the same retained message stream. The map changes per role; the truth does not.

Citizen

Report, follow, and see only what is safe to publish.

Responder

Task-level detail and routing on the ground.

Ops

The whole operational picture, assembled from one stream.

What it does

  • Delivered a unified operational picture for citizens, responders and ops teams from a single canonical state.
  • Used retained MQTT 5 QoS 1 messaging, with Redis as the shared state, so a client joining late still receives the current picture.
  • Wired FastAPI and OneMap SG APIs behind a role-aware MapLibre GL front end.

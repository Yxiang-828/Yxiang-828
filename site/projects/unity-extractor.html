Unity Image Extractor

Project Category: Individual Project (Helper Tools Collection)

Python UnityPy Pillow PNG Export Recursive Scanning

This utility extracts texture assets from Unity bundle files and exports them as PNG images. It is a straightforward project, but it shows a pattern that comes up often in my work: dealing with opaque file formats, building a targeted workflow around them, and turning that into a tool that is actually convenient to use from the command line.

Why it belongs here: even though it is smaller than some of my other projects, it demonstrates applied reverse-engineering workflow, recursive batch processing, and thoughtful output organization rather than just one-off extraction.

What It Does

Bundle Inspection

Reads Unity .unity3d files and identifies image-bearing assets inside the bundle.

Texture Export

Extracts Texture2D and Sprite objects and writes them out as PNG files.

Recursive Scanning

Can process either a single file or a full directory tree when you want to inspect many bundles at once.

Clean Output Structure

Saves output into a predictable directory layout so assets remain traceable to their source files.

Workflow

  1. Accept a Unity bundle file or a directory containing multiple bundles.
  2. Locate UnityFS-compatible data and load it through UnityPy.
  3. Scan for texture and sprite objects inside the parsed asset graph.
  4. Convert extracted image data to PNG and write it into organized output folders.

Usage

py unity_image_extractor.py "path\\to\\file.unity3d"
py unity_image_extractor.py "path\\to\\directory" -r
py unity_image_extractor.py "source" -o "output_dir" -r
